# 114 | Jeu du Simon

Pour le cours I114, nous avons dû faire le jeu du Simon avec un Arduino.

Voici mon programme avec ça [documentation technique](doc.md).

## Installation :

### 1. Cloner le dépôt GitHub
  ``` bash
  git clone https://github.com/pj43svh/projet-simon.git
  ```

### 2. Ouvrir le fichier [projet-simon.ino](projet-simon.ino) avec l'IDE d'Arduino.
### 3. Installer les bibliothèques
Pour faire fonctionner le code, vous aurez besoin de la librairie suivante et vous devrez l’installer dans votre IDE :

  * [Bounce2](https://github.com/thomasfredericks/Bounce2)

### 4. Compiler le code
Sélectionnez "Arduino UNO", puis compilez le programme.

### 5. Jouer
Si la compilation s’est passée sans erreur, vous devriez pouvoir jouer au jeu du Simon ! Appuyez sur le bouton situé sous la LED bleue pour commencer la partie.
